## 一、设计概述

### 1.1 产品定位与设计基调

AI 寻标系统是面向投标企业的 **B2B SaaS 效能工具**，核心链路：寻标 → 匹配 → 建议 → 写标 → 导出 → 复盘。

**设计基调**：专业、克制、高效、可信赖。

| 关键词 | 落地要求 |
| --- | --- |
| 专业 | 信息密度适中偏高，表格与数据可视化为主视觉载体，避免装饰性元素 |
| 高效 | 高频路径（看推送→看匹配→做决策）3 次点击内完成；列表页操作尽量免跳转 |
| 可信赖 | AI 产出（匹配判定、生成文本）必须有"依据来源"可视标记；风险与结论用明确色彩语义 |
| 数据感 | 匹配分、推荐值、中标率等核心数字要大而清晰，配分档色彩 |

### 1.2 用户角色与使用频率（决定页面优先级）

| 角色 | 高频页面 | 设计侧重 |
| --- | --- | --- |
| 商务/市场人员 | 工作台、招标列表、匹配结果、投标建议 | 信息扫读效率、决策操作顺手 |
| 标书撰写人员 | 标书编辑器、合规检查、导出记录 | 长时间编辑舒适度、AI 辅助顺手 |
| 资料管理员 | 企业画像维护 | 表单录入效率、证照上传体验 |
| 租户管理员/管理员 | 系统管理、闭环看板 | 配置清晰度、数据可读性 |
| 观察者 | 工作台、列表、看板（只读） | 所有写操作入口须隐藏而非禁用置灰 |

### 1.3 信息架构与导航结构

左侧一级导航（建议）：

```
工作台
招标信息
  ├─ 信息列表
  ├─ 拟投标清单
  └─ 消息中心（订阅推送）
智能匹配
  ├─ 匹配结果
  └─ 投标建议
标书中心
  ├─ 标书编辑
  ├─ 合规检查
  └─ 导出记录
企业画像
数据看板（闭环优化）
系统管理（管理员可见）
```

整体框架：**顶栏（全局搜索 + 消息铃铛 + 租户/用户）+ 左侧导航 + 内容区**；顶栏全局搜索直达招标列表检索。

### 1.4 设计原则

1. **分数即语言**：匹配分/推荐值是全系统核心语言，所有出现处样式统一（数字+分档标签+可选进度环）；
2. **结论先行**：建议、检查、评估类页面，结论横幅置顶，明细在下；
3. **AI 可解释**：任何 AI 产出内容旁须有"依据"入口（图标统一）；
4. **操作留痕可见**：导出、删除、规则调整等敏感操作有二次确认弹窗，文案说明后果；
5. **权限即隐藏**：无权限的菜单/按钮不展示，避免满屏置灰。

## 二、全局设计规范

### 2.1 布局与适配

| 项 | 要求 |
| --- | --- |
| 设计稿基准 | 桌面端优先，主设计分辨率 1440×900；内容区最小支持 1280 宽 |
| 列表页 | 筛选区（顶部或左栏）+ 表格/卡片结果区 + 分页 |
| 详情/编辑页 | 定宽内容容器（1200px 内），长页面锚点导航 |
| 移动端 | 一期不做功能适配，仅要求消息推送落地页（H5 简版）可浏览 |

### 2.2 色彩语义（核心，须全系统一致）

| 语义 | 建议色值 | 使用场景 |
| --- | --- | --- |
| 主色 | #2563EB（科技蓝） | 品牌、主按钮、链接、选中态 |
| 高匹配（≥80） | #E5484D 红 | "高匹配"标签、分数角标、推荐投标标记 |
| 中匹配（60–79） | 主色蓝 | 中匹配标签 |
| 低匹配（<60） | #8A94A6 灰 | 低匹配标签 |
| 满足/通过/成功 | #2F9E6E 绿 | 条件满足、检查通过、中标 |
| 风险/预警/临近到期 | #F59F0B 橙 | 风险提醒、资质 60 天内到期、待人工确认 |
| 不满足/失败/不建议 | #E5484D 红（深） | 条件不满足、废标风险、未中标 |
| AI 产出标记 | #7C5CFC 紫 | "AI 生成"角标、AI 面板主色 |

分档规则（设计师须背熟）：
- **匹配分三档**：高 ≥80（红）/ 中 60–79（蓝）/ 低 <60（灰）；
- **可行性三档结论**：可投标（绿）/ 有风险（橙）/ 不建议投标（红）；
- **资质有效期**：有效（绿）/ ≤60 天到期（橙）/ 已过期（红）；
- **硬性条件判定**：满足（绿✓）/ 不满足（红✗）/ 待人工确认（橙?）。

### 2.3 字体与排版

| 项 | 要求 |
| --- | --- |
| 中文 | 系统默认无衬线（PingFang SC / Microsoft YaHei） |
| 数字 | 核心分数（匹配分、推荐值、中标率）使用等宽或 DIN 类数字字体，字号放大（24–40px） |
| 层级 | 页面标题 20px / 区块标题 16px / 正文 14px / 辅助说明 12px |
| 表格 | 行高 ≥48px，金额、日期右对齐，分数列居中 |

### 2.4 通用组件需求

| 组件 | 要求 |
| --- | --- |
| 分数徽章 | 数字 + 档位色背景/描边，提供大（详情页）/小（列表角标）两档尺寸 |
| 筛选器 | 地区级联、金额区间、公告类型多选、时间范围；支持"保存为订阅"快捷入口 |
| 状态标签 | 统一标签库：公告类型（招标/更正/中标/废标）、清单状态、审核状态 |
| 截止时间倒计时 | 距投标截止 ≤72h 橙色高亮，≤24h 红色闪烁/强提示 |
| 二次确认弹窗 | 敏感操作（导出、删除、权重调整）统一样式：警示图标 + 后果说明 + 需输入确认词（删除类） |
| 空状态 | 每类列表独立插画 + 引导操作按钮（如"去创建订阅"） |
| AI 依据弹层 | 点击"依据"图标弹出：引用来源（招标条款号/企业资料条目）+ 原文摘录 |
| 时间轴 | 项目详情更正公告、审计日志使用纵向时间轴组件 |

### 2.5 状态与反馈

- **加载**：列表骨架屏；匹配计算（≤30s）与章节生成（≤60s）使用带进度提示的等待态，禁止无反馈转圈超过 3s；
- **推送提醒**：顶栏铃铛红点 + 下拉面板，推送卡片含项目名、匹配分徽章、推送时间、直达按钮；
- **无权限**：页面级无权限显示申请引导（联系租户管理员）；
- **错误**：采集/解析失败类错误提示附"重试"与"反馈"入口。

## 三、页面设计需求（P01–P13）

> 每页按【定位】【布局区块】【关键展示】【核心交互】【状态设计】【设计要点】描述。

### P01 首页/工作台

- **定位**：每日工作起点，"今天有什么值得投的标"一屏解答；全角色可见（观察者只读）。
- **布局区块**（建议栅格）：
  1. 顶部指标卡 ×4：今日新增推送、高匹配项目数、待办事项数、本月导出标书数；
  2. 待办清单（左，占 1/2）：待决策项目 / 待撰写标书 / 资质到期提醒，每项带一键处理按钮；
  3. 高匹配项目 TOP5（右）：项目名 + 分数徽章 + 预算 + 截止倒计时 + "查看匹配"按钮；
  4. 订阅动态流（下）：最近推送摘要，支持按订阅分组筛选。
- **核心交互**：卡片/列表项点击直达项目详情或对应处理页；待办"快速决策"（投/不投）不离开本页。
- **设计要点**：待办为最高优先级视觉区；新用户空状态引导"完善企业画像 → 创建订阅"两步。

### P02 招标信息列表

- **定位**：寻标主阵地，检索 + 筛选 + 初步决策。
- **布局区块**：
  1. 检索栏：输入框 + **关键词/语义检索切换**（语义模式带 AI 紫色标识，输入支持自然语言）；
  2. 筛选器：地区、金额区间、公告类型、发布时间、匹配分档位（快捷筛选"仅看高匹配"）；
  3. 结果表格列：项目名称（可点）、地区、预算金额、投标截止（倒计时）、公告类型、匹配分徽章、操作列；
  4. 操作列：收藏、加入拟投标清单、查看匹配（悬浮显示分数明细缩略）。
- **核心交互**：
  - 默认排序=匹配分降序，可切换时间排序；
  - 当前筛选条件一键"保存为订阅"（弹窗命名 + 推送设置）；
  - 批量操作：批量加入清单。
- **状态设计**：无结果空状态（建议放宽条件/创建订阅）；字段缺失项目（如缺预算）以"—"展示并带提示图标。
- **设计要点**：匹配分角标是扫读焦点；更正版公告在名称后带"更"标记。

### P03 项目详情

- **定位**：单项目全貌，承接"看详情 → 发起匹配 → 进入撰写"。
- **布局区块**：
  1. 头部信息卡：项目名、编号、采购人、预算、开标/截止时间（倒计时）、地区、公告类型标签、来源链接（可溯源）；
  2. 操作条：发起匹配 / 查看匹配报告 / 加入拟投标清单 / 发起标书任务（状态联动置灰）；
  3. Tab 区：结构化信息（字段表）/ 原文快照（含采集时间水印）/ 附件列表 / 变更时间轴（更正公告）/ 关联中标信息。
- **核心交互**：原文快照支持划线选中关键词"以词搜同类项目"；附件支持预览与下载。
- **设计要点**：来源可溯（原文链接+采集时间）必须常驻可见；缺字段明示不隐藏。

### P04 企业画像维护

- **定位**：企业资产录入与维护，资料管理员主战场。
- **布局区块**：
  1. 左侧锚点导航：基本信息 / 资质证照 / 业绩案例 / 团队人员；
  2. 资质区：证照卡片网格（证书名、等级、编号、有效期状态色边框、到期日）+ 右上角"上传证照"主按钮（拖拽上传）；
  3. 业绩区：表格（项目名、金额、时间、甲方、证明材料附件）+ 新增抽屉表单；
  4. 团队区：人员卡片（证书、职称）。
- **核心交互**：
  - 上传证照后展示"解析中 → 解析结果预览（可修正）→ 保存"三步流程；
  - 到期提醒条：顶部横幅列出 60 天内到期证照，点击直达对应卡片；
  - 字段级编辑，未保存离开有挽留提示。
- **设计要点**：有效期状态色（绿/橙/红）是卡片第一视觉；解析结果预览须支持逐字段修改——这是 OCR 容错的关键交互。

### P05 匹配结果

- **定位**：单项目匹配报告页，"为什么是这个分"讲清楚。
- **布局区块**：
  1. 结论横幅：匹配总分（大数字 + 档位色）+ 硬性条件核查结论（全满足/有不满足项红色列出）；
  2. 六维得分：雷达图或横向条形图（资质 30/业绩 25/地域 15/商务 15/技术 10/竞争 5，权重以当期配置为准）；
  3. 逐项判定明细表：要求项 | 判定结果（绿✓/红✗/橙?）| 证据摘录（项目侧原文）| 企业侧依据 | 人工修正按钮；
  4. 底部操作：查看投标建议 / 人工修正汇总提交。
- **核心交互**：人工修正弹窗（改判定 + 填理由），修正后分数重算并留痕标识"含人工修正"。
- **设计要点**：证据引用是信任核心，每条判定必须可视地链接到原文；不满足项置顶展示。

### P06 投标建议（决策页，V1.1 重写：承载六大决策引擎输出 + 决策输出标准化，见 PRD 4.10）

- **定位**：单项目深度研判与决策页，回答"能不能投、怎么投、打不打得赢"。平台定位为上游决策平台：本页决策通过后才进入下游标书撰写。
- **页面骨架（自上而下）**：
  1. **★决策书摘要总览（单一真相源）**：顶部横幅，大字决策结论标识（四档标准词库：GO 绿 / GO 附条件 蓝 / WATCH 橙 / NO-GO 红）+ 总体建议（= 决策结论文 + 策略名 + 前提条件）；须带"★决策书派生 · 不重新解释"标识；五要素摘要条：核心风险 / 关键机会 / 预算匹配度 / 竞争格局 / 推荐策略；
  2. **三层量化匹配评分（E5，P0）**：L1 资质匹配（够不够门槛）/ L2 价格竞争力（报价区间建议 + 异常低价红线）/ L3 履约可行性（能否扛下合同）三层得分条 + 决策综合得分；与原六维匹配分（商机发现阶段）区分展示，不混排；
  3. **四层风险筛查（E1，P0）**：四卡片（致命条款/商务履约大坑/评分定向陷阱/疑似异常信号），每卡红/橙/绿状态 + 发现项数，点击展开风险清单明细（含判定依据：预算与配置匹配度、特殊条款、特定功能特征）；
  4. **市场调研（E2，P1）**：市场规模估算、竞品图谱、政策环境扫描、价格基准线六细分项（中标均价/中位价、预算 vs 历史中标价、异常低价阈值、价格扣除系数、核心产品在产核验、产地合规）；
  5. **历史中标格局（E3，P1）**：同标方历史项目、老服务商依赖度、多服务商博弈、甲方更换倾向、中标后被淘汰可能性五维输出；
  6. **指定性识别（E4，P1）**：内定风险等级（低/中/高）大字结论 + 指标证据列表（硬参数指向/评分结构/资源门槛/主观分占比/案例地区行业指向/人员资质搭配/系统依赖 + 评分离散性空隙/排除性条款/业绩加分难证明三附加项）；必须带"参考性研判"角标（合规定位）；
  7. **策略对比决策矩阵（E6，P1）**：表格 6 列（策略/建议报价/资质组合/综合得分/中标概率/风险等级），≥4 行策略（稳健主攻/进取博弈/低价抢标/战略放弃），推荐策略行高亮；
  8. **执行清单（P0）**：投标前必做 10–15 项具体动作，每项含动作/责任人/截止时间/状态（勾选交互）；
  9. **风险登记表（P1）**：风险项 = 评级 + 责任人 + 时间窗口 + 应对预案；风险等级须与 E1 筛查结果一致（一致性校验项 5）；
  10. **双向预案（P1）**：双栏布局——左"中标后下一步"（合同/履约准备）右"不中标后下一步"（复盘/转投储备项目），体现"不浪费这次投标动作"；
  11. **一致性校验状态（P0）**：交付前 11 项校验清单状态指示（通过项数/打回项），≥3 项不通过时决策书标"打回重做"态；
  12. **决策操作区**：投标（按推荐策略创建标书任务）/ 不投标（必填原因）/ 持续观察（WATCH 态），均写入决策记录；推荐值仪表（Q7 机制，含推荐下限刻度线）保留为侧栏快速参考，与决策综合得分并存不替代。
- **核心交互**：各引擎区块支持折叠/展开；风险清单与风险登记表双向联动（等级一致校验）；策略矩阵行点击可切换"推荐策略"并同步更新总体建议前提条件（需二次确认）；执行清单勾选实时显示完成进度。
- **设计要点**：
  - 决策结论四档标准词库的视觉区分是本页第一优先级，禁止模糊措辞与自造结论；
  - 摘要总览只能派生自决策书，设计上用"★单一真相源"标识强化；
  - 指定性识别与竞品类输出均标注"参考性预警/研判"（合规定位不可省略）；
  - 报价区间在市场调研、策略矩阵、决策书三处必须一致（校验项 3），前端由同一数据源渲染；
  - 推荐下限刻度线（Q7 机制）与"参考性预警"措辞要求继续有效。

### P07 标书编辑

- **定位**：系统最复杂页面，长时间作业场景。
- **布局区块（三栏）**：
  1. 左栏：目录树（章节层级）+ **响应点清单对照**（每个响应点应答状态：未应答灰/已应答绿/遗漏红）；
  2. 中栏：富文本编辑区；段落级 AI 标记（紫色角标=AI 生成，悬停显示"采纳/弃用/查看依据"）；顶栏工具：保存、版本历史、版本对比、提交审核；
  3. 右栏：AI 助手面板——整章生成/续写/改写/缩写操作区、模板选择（内置/企业模板）、生成记录。
- **核心交互**：
  - 整章重生成有确认弹窗（覆盖提示）；
  - 版本对比双栏视图（增删高亮）；
  - 响应点遗漏时左侧红点 + 顶部汇总条提醒；
  - 自动保存（30s）状态常驻显示。
- **状态设计**：生成中显示逐段输出动效；审核中锁定编辑并显示审核状态条。
- **设计要点**：三栏可折叠（小屏收右栏）；AI 生成内容与人工内容的视觉区分必须一眼可辨（真实性红线的设计支撑）。

### P08 合规检查

- **定位**：导出前的最后一道闸。
- **布局区块**：
  1. 检查概览：真实性校验 / 格式检查 / 敏感信息检查 三卡片（通过绿/问题数红）；
  2. 问题清单：按类别分组，每项含严重级别图标、问题描述、"定位到正文"按钮；
  3. 底部：**全部通过 → 解锁"导出"主按钮**；未通过时导出按钮禁用并提示原因。
- **核心交互**：点击问题项跳转编辑器对应位置并高亮；修正后可单项复检。
- **设计要点**：真实性问题（引用了画像中不存在的业绩/资质）用最高警示级别红色横幅——这是产品红线。

### P09 导出记录

- **定位**：导出档案与样式确认。
- **布局区块**：
  1. 导出前（弹窗流程）：样式配置面板（字体/页边距/行距/页眉页脚/红头标题与文号）+ 排版预览 + **"招标要求 vs 当前样式"对照清单**（逐项核对打勾，F7-7）；
  2. 记录表格：导出时间、操作人、关联版本、文件名、格式、重新下载。
- **设计要点**：样式对照清单逐行"要求值 / 当前值 / 一致✓"三列展示；红头效果须在预览中真实渲染。

### P10 闭环看板（数据看板）

- **定位**：管理层复盘与策略调优入口。
- **布局区块**：
  1. 指标卡：推荐率（附当期推荐下限标注）、中标率、采纳项目数、平均匹配分；
  2. 趋势图：推荐率/中标率按月趋势；
  3. 失分归因：瀑布图/条形图（按章节与失分原因）；
  4. 对手对比表：主要竞争对手、其中标次数、报价区间（若有）；
  5. 下钻：点击指标进入项目明细列表。
- **设计要点**：**推荐率必须标注统计口径（当期推荐下限值）**——口径随用户设置变化，不标注会误导决策（PRD 4.8 明确要求）。

### P11 系统管理

- **定位**：租户管理员/管理员的配置中心。
- **子页面**：
  1. 成员与角色：成员表格 + 角色分配（六角色下拉）+ 邀请；
  2. 数据源管理：源列表（通道类型 A/B、授权依据、合规审查状态、采集成功率、延迟监控图表）；
  3. 规则库：六维权重滑块/输入（实时合计校验=100%）+ 版本历史 + 回滚按钮；
  4. 模板库：内置/企业模板卡片管理；
  5. 审计日志：时间轴 + 筛选（操作类型/人/时间），只增不改的视觉暗示（无编辑入口）。
- **设计要点**：权重调整保存须二次确认并展示"将影响后续匹配计算"；审计日志导出为敏感操作样式。

### P12 登录与引导（辅助页）

- **登录**：账号密码 + 短信/邮箱验证码；管理员角色登录后触发 MFA 二次验证页；连续失败锁定提示；
- **注册/开通**：企业信息 → 管理员账号 → 完成；
- **新手引导**：首次进入三步任务条——①完善企业画像 ②创建第一个订阅 ③查看第一条匹配推送（完成度可视化）。

### P13 消息中心（辅助页）

- **定位**：订阅推送与系统通知聚合。
- **布局**：通知分组（订阅推送/资质到期/审核通知/系统公告）；推送卡片含匹配分徽章与直达按钮；支持全部已读、按订阅筛选；
- **设计要点**：未读红点与顶栏铃铛联动；推送卡片点击直达项目详情并自动定位匹配区。

## 六、设计交付物与验收标准

### 6.1 交付物

1. 高保真设计稿：P01–P13 全部页面（1440 基准），含本文要求的各状态（空/加载/错误/无权限）；
2. 组件库：2.4 所列通用组件 + 分数徽章/状态标签全套规格；
3. 交互标注：核心任务流 A/B/C 的跳转与反馈标注；
4. 权限标注：每个页面注明角色可见性（对照第四章表格）。

### 6.2 验收标准（关键项）

| # | 验收项 |
| --- | --- |
