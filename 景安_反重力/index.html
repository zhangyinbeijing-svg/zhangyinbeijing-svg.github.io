多策略精细化管控方案

Multi-Strategy Scheme · 按组织架构定制
适用复杂合规组织

支持管理员创建多条互相独立的生命周期策略，按“全员、指定部门、指定账户、指定域名”灵活划分适用范围，并配备健全的多方命中判定机制。

  • 多维度适用范围：可为高管/财务定制保留 7 年，常规部门保留 3 年，临时或测试域保留 180 天。
  • 核心冲突判定机制：独创“最长保留原则”；当一封邮件的发件人、收件人、抄送人命中不同策略时，以最长保留期限为准，全部方超期后才销毁。
  • 多策略增删改查：支持策略优先排序、启停控制、即时单策略执行清理与统计看板。
  • 高亮悬浮 Popover 说明：在列表关键表头与操作区提供鼠标悬浮规则解释弹层，降低使用疑虑。
典型适用客户
大型集团、银行金融机构、上市公司或各部门数据保密级别差异巨大的跨国企业。

单一策略极简统一方案

Single-Policy Scheme · 全局统一一目了然
适用统一合规标准

全系统仅维护一个全局唯一的系统生命周期策略，免配置策略名称、免配置适用范围、无多方判定冲突，策略看板与清理日志一体化直呈。

  • 全系统全局生效：全系统所有归档邮件遵循唯一明确的时效标准（如统一保留 3 年 0 月 0 天）。
  • 零冲突判定成本：所有发件人与收件人享受完全相同的时间基准，杜绝策略重叠、配置混淆与误删隐患。
  • 看板+日志一体化直呈：页面上方常驻系统策略卡片，下方直接呈现批次清理审计列表，操作路径极短。
  • 支持即时执行：除每日凌晨定时调度外，支持管理员随时一键“立即执行清理”，实时查看释放成效。
典型适用客户
追求极致操作简便、团队运维精力有限、企业内部执行全员统一合规归档制度的中小及中大型政企单位。

底层共性机制与架构保障

两套方案均继承并共享 ES Mail 本地邮件归档的高可用清理引擎底座

双向物理彻底销毁
清理任务执行时，不仅从磁盘彻底物理抹除邮件本体（.eml / .msg 及其嵌套附件），同时向 Elasticsearch 集群发出批量清理指令，抹除元数据与全文倒排索引，确保释放存储并保护合规隐私。
调度引擎与防雪崩限速
默认设定于业务低峰期（如每日凌晨 02:00）调度执行；采用游标分页分批检索（每批次 5,000 封），辅以 IO 缓冲降速算法，彻底避免超大规模清理导致系统 CPU 突增或磁盘 IO 阻塞。
审计闭环与数据安全
所有清理批次均产生全局唯一批次号（TASK-YYYYMMDD-XXXXX），详细记录扫描数、删除文件数、清除索引数与释放容量；提供前 50 条清理抽样明细可信核验，确保合规溯源有据可查。
